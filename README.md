# Python Learning & Practice Repository 🚀

Welcome to my Python repository! This collection contains various practice programs, core concepts, algorithms, and problem-solving exercises developed during my journey of learning and mastering Python.

---

## 📂 Project Structure & Topics Covered

Here is an overview of the modules and topics available in this repository:

* **`Calculator/`**: Basic and advanced calculator scripts along with Fibonacci sequence implementations.
* **`Def_function/ & Functions/`**: Custom functions, default/named parameters, and modular programming concepts.
* **`Control_Statement & For_loop/`**: Conditional statements (`if-elif-else`), `for` loops, `while` loops, nested loops, and pattern problems.
* **`List_functions/ & List/`**: List operations, methods, iteration by index, list comprehensions, and slicing.
* **`Dictionary/`**: Dictionary methods, adding/updating key-value pairs, and search/sorting logic.
* **`Sets/`**: Set operations, type conversions, common elements, and set methods.
* **`Strings & String_methods/`**: String manipulation, slicing, ASCII codes, palindrome checkers, split methods, and character counting.
* **`Exceptional_handling/`**: Handling runtime errors, try-except blocks, and multiple exceptions.
* **`Leetcode Questions/ & Online_Questions/`**: Solutions to various coding interview questions and string parsing problems.
